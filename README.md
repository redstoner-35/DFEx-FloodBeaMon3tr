### 概述

欢迎来到由Redstoner_35所开发的新一代高功率全恒流泛光手电**DFEX GT-X2,aka. DFEx-FloodBeaMon3tr**的完整设计开源仓库。DFEX GT-X2是基于全新的XTR HyperBoost HV GaN超高能效氮化镓升压恒流驱动所实现的大型手电参考设计。该手电作为低压增强型氮化镓功率器件在手电行业的首次应用，提供了以往硅基MOSFET方案无法企及的性能和功率密度。该手电方案具备行业首个基于氮化镓功率管的全恒流双相交错升压驱动，提供高达**153600LM 520000CD**的峰值出光性能，并且只需四节21700电池即可驱动。手电同时标配超低内阻的免工具可换电池电池架，内置140W双向充电方案。用户可以随心所欲地更换电池从而在户外实现极强的续航。并且该电池架具备行业主流的手电电池组方案所缺失的高级BMS功能和大电流主动均衡，使得电池子系统即使在用户可换电池和极高充放电倍率的条件下仍然能保障安全和稳定运行，电池子系统会通过其内置的BMS前端自动完成电池一致性管理，并允许用户随时查询电池的运行状况。这意味着用户可以装入电池后将手电当成电池棒手电全程不拆电池使用，并通过内置的140W快充模块在45分钟内完成快速充电（四节鹏辉能源60Q 84Wh的0-100%充电时间41分钟）。标配的高速风扇手柄DLC可以实现高达45000LM的持续常亮性能，提供无与伦比的常亮输出。

### 手电大致性能

+ 手电尺寸：21.5cm总长，10cm头径（未包括风扇手柄）
+ 手电重量：2070克（未包含风扇把手DLC） / 2355克（包含风扇把手DLC）
+ 电池组件：标配内置BMS和高性能主动均衡的电池架。用户可换电芯无需任何工具。
+ 电池架对电芯的需求：四节一致性良好的21700尺寸圆柱三元锂全极耳动力电芯。需具备至少100A的带温控截止放电能力（对于电芯的选择，请参考下方内容）。
+ 充放电方式：内置140W PD3.1/PD3.0多协议双向充放电子系统。该子系统支持标准和非标准PD3.0 Fix和PPS，以及PD3.1 EPR和AVS。用户也可拆下电池充电。
+ 出光峰值性能：153600LM光通量 520000CD光强 ANSI标准1440米射程

### 复刻时电池的选择

这个手电的电池在工作过程中需要承受巨大的电流。在Power模式极亮的时候，电池最高电流可达105-110A。虽然固件具备有自适应输入MPPT算法，但是使用容量型或者半动力型电芯仍然可能会导致电芯出现不可逆的性能下降甚至损坏！因此为了保证您的安全，我仅推荐使用如下的电芯：

+ 鹏辉能源60Q：6000mAh超高倍率全极耳，也是作者在完成续航测试全过程时所使用的电池。
+ 新能安JP50P2：5000mAh版本的JP40，具有极强的放电能力，在牺牲了续航的前提下换来了更高的寿命。
+ 天鹏50XG：5000mAh超高倍率动力电池的标杆。
+ 天鹏40XG：支持90A持续放电，虽然续航惨不忍睹但是胜在便宜量大管饱。续航不够就多带电池。

### 风扇手柄DLC的说明

#### 风扇手柄操作逻辑

该风扇手柄DLC自身具备独立的操作按钮和系统,允许用户根据需要调整输出功率。风扇手柄本身包含自己的驱动和电池，不占用手电本身电池的电力和驱动面积。对于完整的操作逻辑，您可查看风扇手柄固件文件夹内的[风扇手柄操作说明](/%E5%9B%BA%E4%BB%B6/%E9%A3%8E%E6%89%87%E6%89%8B%E6%9F%84%E5%9B%BA%E4%BB%B6/Fan_Readme.md)。同时，为了实现极致的高常亮，作者在2026年9月3日的版本更新提供了43000RPM的超暴力风扇把手。该把手采用单锂升压设计，支持51W的超级风扇。为了实现如此高的输出功率，作者提供了全新的风扇驱动，操作逻辑和旧版略有修改。您克查看新版本风扇手柄固件文件夹内的[新版本风扇手柄操作说明](/%E5%9B%BA%E4%BB%B6/%E7%A6%81%E8%B5%9B%E7%BA%A7%E9%A3%8E%E6%89%87%E6%89%8B%E6%9F%84%E5%9B%BA%E4%BB%B6%E6%BA%90%E7%A0%81/Fan_Readme.md)。

![风扇手柄正面](/img/%E9%A3%8E%E6%89%87%E6%89%8B%E6%9F%84%E6%AD%A3%E9%9D%A2.jpg)

该风扇手柄DLC基于自主开发的单锂升压12V风扇专用驱动以及单锂双向充电板，手柄样机所标配的风扇为建准的XF40281BX-Q035-S9H。转速高达34000RPM可以实现4.5万LM常亮不降档（2026年9月3日新增43000RPM的超暴力风扇手柄，吹称200克，支持5万常亮）。同时该风扇手柄的电池仓为免拆电池充电设计，旋下电池仓即可露出内置的双向USB-TypeC充电接口：

该充电接口支持双向5V 2.4A充放电。最高12W的输入或输出功率。除了能给风扇手柄充电以外在应急情况下还可以反向为手机或其他设备应急充电。拆下手柄后即可看到手柄电池仓正面的充放指示灯：

![正面指示灯位置](/img/%E6%89%8B%E6%9F%84%E7%94%B5%E6%B1%A0%E6%9E%B6%E6%8C%87%E7%A4%BA%E7%81%AF.PNG)

手柄的电池仓一共包含两个指示灯，其中一个为放电和电池电量指示灯（图中紫色并且以放字标识的LED）以及一个充电状态指示灯（图中黄色以充字标识）负责指示电池的充放电状态。当电池仓首次装入电池时，电量指示灯会1Hz慢闪四秒表示电池安装后系统处于激活锁定模式。此时C口不能对外放电，需要连接充电器充电后才可放电。这两个指示灯不会同时点亮，显示的逻辑如下：

+ 充电指示灯：正在充电时0.5Hz慢闪，充满后持续点亮
+ 放电和电量指示灯：正在放电且电量正常时常亮，正在放电且电量不足后1Hz慢闪（充电或者放电结束拔下线缆后，电量指示灯仍然会保持点亮或闪烁一段时间，用户无需理会。30秒后电量指示灯会自然熄灭）

### 工程结构

该开源手电项目的工程分为三个文件夹，分别放置手电的电子、机械和固件部分的原始资料：

+ PCB：该文件夹放置手电所有功能模块的电路板文件
+ 固件：该文件夹放置手电种各个功能模块所使用到的固件文件
